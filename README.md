## 系统要求

- Windows 10 及以上（x64）
- 安装包未做代码签名，首次运行可能出现 SmartScreen 提示，选择「更多信息 → 仍要运行」即可

## 数据位置

- 配置与会话数据库：`%APPDATA%\ImaginAI`
- 图库图片：安装目录下 `library\<会话ID>\<日期>\`
